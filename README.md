# Ganga Cushions — website package

A responsive static website for Ganga Cushions, Shrirampur. It uses illustrative stock photography, a light professional colour palette, WhatsApp enquiry links, a click-to-call link, Google Maps directions, basic local-business structured data and page metadata.

## Before publishing

1. Check the business phone number and address in `index.html`.
2. Confirm that each listed service is genuinely offered. Remove any service that does not apply.
3. Confirm current opening hours and add them only if you want them displayed; this first version deliberately does not guess hours.
4. Review the generic stock photos and their licensing/attribution requirements at the source before commercial use. The photos are illustrative, not photos of Ganga Cushions products or premises.
5. Replace the placeholder GitHub URL in any social profiles only after publishing.

## Publish free with GitHub Pages

1. Sign in to GitHub and create a **public** repository named `ganga-cushions-website`.
2. Open the repository, choose **Add file → Upload files**.
3. Upload the contents of this folder (not the outer folder itself): `index.html`, `README.md`, and the `assets` folder.
4. Commit the upload to the `main` branch.
5. Open **Settings → Pages**.
6. Under **Build and deployment**, choose **Deploy from a branch**.
7. Choose branch `main`, folder `/ (root)`, then **Save**.
8. Wait for deployment. The site URL will be `https://YOUR-GITHUB-USERNAME.github.io/ganga-cushions-website/`.
9. Open the URL on a phone and test every call, WhatsApp and directions link.
10. In **Settings → Pages**, enable **Enforce HTTPS** when the option appears.

GitHub Pages on GitHub Free requires a public repository. The source repository is publicly viewable, so do not put passwords, customer data, private quotations or other confidential information in it. Hosting is free within GitHub Pages' terms and limits; a custom domain is optional and normally costs money.

## Add the website to Google Business Profile

1. Publish the site first and confirm the URL loads over `https://` on mobile data.
2. Sign in to the Google account that manages Ganga Cushions.
3. Search Google for `Ganga Cushions` while signed in, or open the profile in Google Maps.
4. Select **Edit profile**.
5. Find **Contact** (or the website field in the current editor), enter the complete `https://...` website URL and save.
6. Wait for Google's review/update, then open the public profile and test the website link.
7. If the profile editor offers social links, add the official Instagram profile after it is created. Add WhatsApp using Google's chat/contact option if available for the profile.

## Contact and enquiry behaviour

The enquiry form does not store data on this website or send email. It builds a pre-filled WhatsApp message and opens WhatsApp for the customer to send. Customers can edit the message before sending.
