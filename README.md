# Ganga Cushions website — Version 2

Mobile-first static website for Ganga Cushions, Shrirampur.

## Publish/update on GitHub Pages

1. Download and extract this ZIP.
2. Open the repository: https://github.com/ganga-cushions/ganga-cushions.github.io
3. Choose **Add file → Upload files**.
4. Upload `index.html`, `assets/` and `README.md` from this folder (upload the contents, not the outer folder).
5. Commit changes to the `main` branch.
6. GitHub Pages is already configured to publish from `main` / root. No settings change is needed.
7. Wait a few minutes, then open https://ganga-cushions.github.io/ and refresh.

## Included
- `index.html`
- `assets/styles.css`
- `assets/script.js`
- `assets/favicon.svg`

## Notes
- Images are illustrative Unsplash stock photography and load from the internet.
- The enquiry form opens WhatsApp with the visitor's entered details. It does not store submissions or create invoices.
- Confirm all business details and service availability before promoting the site.
- This is a static site; no paid hosting or custom domain is required for the GitHub Pages URL.
